# PRD：多用户专属 AI Agent 助手

## 1. 解决什么问题？
传统大模型无法获取本地私有数据（易产生幻觉），无法提供实时信息（如天气），且单窗口对话难以满足多任务隔离的需求。

## 2. 给谁用？
需要管理个人/团队私有知识库、需要多话题并行处理，且要求隐私数据完全隔离的个人或团队用户。

## 3. 第一版范围（做什么）
- **多用户与多话题隔离**：基于 SQLite 实现用户和话题数据的双重隔离，刷新页面数据不丢失。
- **RAG 检索增强**：本地私有文档向量化（ChromaDB），提问时精准召回，拒绝胡编乱造。
- **工具调用（Function Calling）**：接入高德地图 API，AI 自主判断并查询实时天气。
- **流式交互体验**：前端实现打字机效果，侧边栏支持历史话题的无缝切换与删除。

## 4. 暂不做什么（边界）
- 第一版不涉及复杂的账号密码登录体系（暂时通过下拉框模拟多用户切换）。
- 第一版暂不提供后台文档管理页面（私有文档暂存于后端本地）。

## 5. 怎样算完成（验收标准）
- 用户在输入框提问，AI 能流式输出回答。
- 问“公司愿景”等私有文档内容，AI 能准确回答；问天气，AI 能给出实时播报。
- 左侧话题栏能自由新建、切换和删除，历史记录不串线
