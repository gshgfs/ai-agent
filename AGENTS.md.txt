# AI 协作开发规则 (AGENTS.md)

本项目由严悦心与 AI 结对完成。请后续参与本项目的 AI 严格遵循以下规则：

## 1. 先读什么
修改代码前，先阅读 `main.py` 中的 FastAPI 路由结构、数据库模型（SQLAlchemy）以及前端的请求逻辑。

## 2. 可以改哪里
- 允许修改前端 HTML/CSS，优化流式渲染的 UI。
- 允许优化 Prompt 模板（如 System Prompt 的防幻觉约束）。
- 允许增加新的工具函数（如添加搜索功能）。

## 3. 哪些事不能做（红线）
- **严禁**将 API Key 等敏感信息硬编码到代码中，必须通过 `.env` 环境变量读取。
- **严禁**移除 `.gitignore` 文件。
- **严禁**在执行 `git commit` 时提交 `chat_history.db` 和 `chroma_db` 目录。

## 4. 怎么检查
AI 生成的代码，必须在本地终端通过 `uvicorn main:app --reload` 启动，且人工在浏览器验证流式输出、多用户隔离、RAG 检索、天气查询均无异常后方可合入。
