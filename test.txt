这是由严悦心与AI相互交互，独立完成的全栈 AI Agent 项目。本项目包含以下六大核心亮点：

介绍一：多用户与多话题独立记忆。本项目通过接入 SQLite 数据库，实现了强大的多用户隔离功能。不同的用户（如用户A和用户B）拥有完全独立的历史聊天记录，互不干扰。并且，即使用户刷新网页或服务器重启，所有的话题和历史记录都会永久保存。

介绍二：RAG 文本检索功能。系统接入了 ChromaDB 向量数据库，能够读取本地私有文档并进行向量化存储。当用户提问时，AI 会先从知识库中精准检索相关段落，再结合大模型生成回答，彻底杜绝胡编乱造，实现真正的专属知识库问答。

介绍三：实时天气查询与工具调用。项目接入了高德地图 API，实现了 Function Calling 工具调用功能。当用户询问天气时，AI 能够自主判断意图，调用外部接口获取实时天气数据，并给出贴心的穿衣建议。

介绍四：流式输出体验。前端与后端通过 Server-Sent Events 技术，实现了极致的流式打字机效果。用户无需等待，可以看到 AI 一个字一个字地实时生成回复，交互体验极佳。

介绍五：核心技术栈。本项目的后端基于 Python 的 FastAPI 框架开发，使用了 SQLAlchemy 操作数据库。向量检索使用 ChromaDB，大模型接入的是 DeepSeek 的 API。前端则使用原生的 HTML、CSS 和 JavaScript 编写。

介绍六：独立开发完成。该项目从环境搭建、后端接口开发、数据库设计到前端界面美化，全部与AI助理协同探索，独立完成。这是一个具备生产级雏形的全栈 AI 应用。
